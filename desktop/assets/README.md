# Zatwierdzony wygląd Studio

`approved-design.png` to zatwierdzona przez użytkownika plansza koncepcyjna. `home-illustration.png` jest oryginałem ilustracji ImageGen, a WebP jej zoptymalizowaną wersją. Pełne prompty zapisano w `BRIEF.txt`.

Produkcyjny widok w `desktop/ui` pochodzi z zatwierdzonego interaktywnego projektu Studio: ten sam układ, ilustracja, monogram, Manrope, kolory i proporcje. Zasoby osadzono lokalnie; UI nie pobiera grafik/fontów z internetu. Przykładowe zadanie i litera D w ustawieniach są wyłącznie podglądem wyglądu. Ekran Start, modele, konta, historia i wyniki analizy używają rzeczywistych danych.

Instalator i deinstalator rozszerzają ten sam styl. Runtime interfejsu: Microsoft WebView2; operacje Windows i dostawcy działają w warstwie natywnej, przez ograniczone komunikaty. Licencje Manrope oraz innych zależności są w dołączonych informacjach licencyjnych.
