## Dane użytkownika i podpis Androida

Prywatny snapshot jest w `_lokalne/dane-aplikacji-2026-11-10`.
Obejmuje własny magazyn rozszerzenia OKStudy z Chrome (tylko tę wtyczkę),
przenośny eksport jego wartości do JSON, konfigurację Native Messaging,
klucz podpisu Androida wraz z istniejącym plikiem hasła oraz klucz API
z historycznego folderu. Źródłowe i skopiowane pliki porównano SHA-256;
sprawdzono stabilność plików Chrome oraz CRC i strukturę dziennika LevelDB.

W lokalnym magazynie rozszerzenia znaleziono trzy zapisane wartości,
w synchronizowanym — zero. Trwałej historii nie znaleziono; nie było także
pliku ustawień/historii desktop. Historia przechowywana tylko w RAM sesji
przeglądarki nie jest plikiem tej kopii. Nie kopiowano innych danych Chrome,
cookies ani sesji kont. Logowanie ChatGPT chronione DPAPI pozostaje na Bazie
i należy je wykonać ponownie na laptopie. Nie odszyfrowywano jego tokenów.

`mobile/private/` pozostaje w wymaganym miejscu dla budowania Androida.
Jego kopia jest w paczce prywatnej; klucz i hasło nie trafiają do Git ani
paczki kodu. Prywatne załączniki pozostają również w paczce danych.
Oryginalny magazyn rozszerzenia i instalacji użytkownika nie był modyfikowany.

sumy SHA-256 i CRC istniejących paczek. Zmiany porządkowe nie modyfikują

rzeczywistych kont, płatnego API ani prób Androida/iOS.
